# Update Bundle

This folder contains the latest project files to copy into your Godot project.

## Quick use

1. Copy everything inside `update_bundle/` into your project root.
2. Overwrite existing files when prompted.
3. Open Godot and run the project.

## Verify bundle integrity

Use `MANIFEST.sha256` to confirm file hashes if needed.

Read `BUNDLE_VERSION.txt` to confirm which commit this bundle came from.
